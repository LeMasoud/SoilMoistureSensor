# فایل
فایل‌های قرار گرفته در این بخش را می‌توان به نرم‌افزار‌های مختص به طراحی مدار معرفی کرده و نسبت به طراحی اقدام کنید.

## AHT20
با توجه به هم خانواده بودن حسگر‌های AHT در حال حاضر تنها به ارائه مدل حسگر AHT20 اکتفا نموده‌ام.
تصویر زیر نمایش دهنده شکل حسگر AHT20[^1] در حال حاضر است.

![Adafruit AHT20 Temperature and Humidity Sensor](/documents/schematics/parts/Adafruit_AHT20_Temperature_and_Humidity_Sensor.jpg)

## Capacitive
مجموعه حسگر‌های خازنی[^2] بصورت عمومی از طراحی یکسانی برخوردارند و مدل طراحی شده توسط شرکت DFRobots مورد استفاده قرار گرفته است.

![DFRobot_Capacitive_Soil_Moisture_Sensor_V1](/documents/schematics/parts/DFRobot_Capacitive_Soil_Moisture_Sensor_V1.jpg)
