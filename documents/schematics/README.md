# مدارات
طراحی محصول شامل مدارات آن می‌شود که به صور مختلف ارائه می‌شوند.
این طراحی‌ها را می‌توان بصورت سیمکشی، شماتیک و طراحی برد نمایش داد که در ادامه نمایش داده می‌شوند.

## سیمکشی
سیمکشی نمونه آزمایشی بر روی بردبورد یا بوسیله اتصالات سیمی انجام می‌شود.
این طراحی اولیه بسیار ساده بوده و می‌تواند براحتی نحوه عملکرد مدار را بنمایش در آورد.

![سیمکشی مدارات](/documents/schematics/Breadboard.jpg)

## شماتیک
در شماتیک نمایش داده شده می‌توان ایده کلی از نحوه برقراری اتصالات بمنظور طراحی برد مدار چاپی را مشاده کرد.

![شماتیک مدارات](/documents/schematics/Schematics.jpg)
