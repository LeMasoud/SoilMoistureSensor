# مقالات

>مقالات به مطالب یا مقاله‌هایی اشاره دارند که راهکار‌هایی برای نحوه تولید محصول ارائه می‌کنند. بخشی از آنها بصورت فایل PDF قابل ارائه خواهند بود و سایر آنها می‌توانند بصورت لینک ارائه شوند. تلاش بایستی بر آن باشد که مقالات بصورت PDF در همین بستر ارائه شوند تا از هرگونه چالش در دسترسی به منابع پیشگیری کرده باشیم. اشاره به لینک مقالات یا وبسایت‌ها بایستی با سایرین به بحث گذاشته شود تا راهکاری مناسب برای محلی کردن دسترسی به آنها فراهم شود..
